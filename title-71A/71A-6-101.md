# Utah Code § 71A-6-101. State Veterans Nursing Home -- Definitions.

- (1) As used in this chapter:
  - (a) "Administrator" means a state veterans nursing home administrator selected in accordance with Section 71A-6-103.
  - (b) "Board" means any state veterans nursing home advisory board.
  - (c) "Home" means any state veterans nursing home.
- (2) Terms defined in Section 71A-1-101 apply to this chapter.
