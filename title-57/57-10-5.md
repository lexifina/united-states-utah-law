# Utah Code § 57-10-5. Descriptions of tracts extending over more than one zone.

- (1) If a single land description defines a tract of land that extends from one coordinate zone into another coordinate zone, a person may refer the positions of boundary points to either zone.
- (2) When using a coordinate, a person shall identify in the land description which coordinate zone the person uses.
