# Utah Code § 58-37c-114. Penalty for unlawful conduct.

- (1) A violation of an unlawful conduct provision defined in Subsections 58-37c-101(11)(a) through (j) is a class A misdemeanor.
- (2) A violation of the unlawful conduct provision defined in Subsection 58-37c-101(11)(k) is a second degree felony.
