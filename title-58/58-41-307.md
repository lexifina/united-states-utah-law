# Utah Code § 58-41-307. Single license for speech-language pathologist and audiologist -- Single fee.

- (1) An applicant who qualifies to be licensed as both a speech-language pathologist and audiologist shall receive a single license reflecting licensure in both classifications.
- (2) The division may assess a fee only for a single license.
