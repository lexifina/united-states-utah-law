# Utah Code § 70A-12-103. Relation to Chapter 9a, Uniform Commercial Code - Secured Transactions and consumer laws.

- (1) If there is conflict between this chapter and Chapter 9a, Uniform Commercial Code - Secured Transactions, Chapter 9a, Uniform Commercial Code - Secured Transactions, governs.
- (2) A transaction subject to this chapter is subject to any applicable rule of law that establishes a different rule for consumers and Title 70C, Utah Consumer Credit Code.

Enacted by Chapter 322, 2026 General Session
