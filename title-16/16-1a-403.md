# Utah Code § 16-1a-403. Address in filing.

If a provision in this chapter, other than Section 16-1a-410, requires that a record state an address, the record shall state:
- (1) a street address in this state; and
- (2) a mailing address in this state, if different from the address described in Subsection (1).

Enacted by Chapter 93, 2026 General Session
