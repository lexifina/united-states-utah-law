# Utah Code § 23A-13-101. Definitions.

As used in this chapter:
- (1) "Migratory bird" means the same as that term is defined in 16 U.S.C. Sec. 715j.
- (2) "Migratory bird production area" means an area of land that is:
  - (a) created under this chapter; and
  - (b) used according to the description in Subsections 23A-13-201(1)(b)(iii)(A) and (B).
