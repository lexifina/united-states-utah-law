# Utah Code § 11-58-504. Amendment to a project area plan.

- (1) The authority may amend a project area plan by following the same procedure under this part as applies to the adoption of a project area plan.
- (2) The provisions of this part apply to the authority's adoption of an amendment to a project area plan to the same extent as they apply to the adoption of a project area plan.
- (3) If an amendment to a project area plan results in land being included in the project area that was not included in the project area before the amendment, the base taxable value applicable to the project area before the amendment applies to the land added to the project area by amendment.

Amended by Chapter 535, 2024 General Session
