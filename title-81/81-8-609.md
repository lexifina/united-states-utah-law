# Utah Code § 81-8-609. Procedure to register child support order of another state for modification.

- (1) A party or child support services agency seeking to modify, or to modify and enforce, a child support order issued in another state shall register that order in this state in the same manner provided in Sections 81-8-601 through 81-8-608 if the order has not been registered.
- (2) A petition for modification may be filed at the same time as a request for registration, or later.
- (3) The pleading shall specify the grounds for modification.
