# Utah Code § 81-7-101. Definitions for chapter.

As used in this chapter:
- (1) "Alimony" means the same as that term is defined in Section 81-4-101.
- (2) "Child support" means the same as that term is defined in Section 81-6-101.
- (3) "Child support services" means the same as that term is defined in Section 26B-9-101.
- (4) "Delinquent" means a payment for child support that is overdue.
- (5) "Obligee" means the same as that term is defined in Section 81-6-101.
- (6) "Obligor" means the same as that term is defined in Section 81-6-101.
- (7) "Support order" means the same as that term is defined in Section 81-6-101.
- (8) "Tribunal" means the same as that term is defined in Section 81-6-101.
