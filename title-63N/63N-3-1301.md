# Utah Code § 63N-3-1301. Definitions.

As used in this part:
- (1) "Cannabinoid processor license" means the same as that term is defined in Section 4-41-102.
- (2) "Cannabinoid product" means the same as that term is defined in Section 4-41-102.
- (3) "Industrial hemp product" means the same as that term is defined in Section 4-41-102.
- (4) "Industrial hemp producer registration" means the same as that term is defined in Section 4-41-102.

Amended by Chapter 114, 2025 General Session
