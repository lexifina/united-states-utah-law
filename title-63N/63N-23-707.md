# Utah Code § 63N-23-707. Applicability to an existing first home investment zone or community reinvestment project.

If a parcel within a first home investment zone is included as an area that is part of a project area, as that term is defined in Section 17C-1-102, and created under Title 17C, Chapter 1, Agency Operations, that parcel may not be triggered for collection unless the project area funds collection period, as that term is defined in Section 17C-1-102, has expired.
