# Utah Code § 15A-2-101. Title -- Adoption of code.

- (1) This chapter is known as the "Adoption of State Construction Code."
- (2) In accordance with Chapter 1, Part 2, State Construction Code Administration Act, the Legislature repeals the State Construction Code in effect on July 1, 2010, and adopts the following as the State Construction Code:
  - (a) this chapter;
  - (b) Chapter 3, Statewide Amendments Incorporated as Part of State Construction Code;
  - (c) Chapter 4, Local Amendments Incorporated as Part of State Construction Code; and
  - (d) Chapter 6, Additional Construction Requirements.

Amended by Chapter 95, 2023 General Session
