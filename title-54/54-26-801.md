# Utah Code § 54-26-801. Program duration.

The provisions of this chapter apply only to:
- (1) large load customers, large-scale generation providers or qualified electric utilities which enter into a large load service contract which provides for service to commence on or before December 31, 2034; and
- (2) large load customers and large-scale generation providers which enter into a private generation contract which provides for service to commence on or before December 31, 2034.

Enacted by Chapter 318, 2025 General Session
