# Utah Code § 53G-1-103. Definitions.

As used in this title:
- (1) "DOD civilian" means the same as that term is defined in Section 53H-11-202.
- (2) "Electronic cigarette product" means the same as that term is defined in Section 76-9-1101.
- (3) "Military service member" means the same as that term is defined in Section 53H-11-202.

Amended by Chapter 9, 2025 Special Session 1
