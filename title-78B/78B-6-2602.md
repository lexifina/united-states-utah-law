# Utah Code § 78B-6-2602. Filter required.

All devices activated in the state shall:
- (1) contain a filter;
- (2) ask the user to provide the user's age during activation and account set-up;
- (3) automatically enable the filter when the user is a minor based on the age provided by the user as described in Subsection (2);
- (4) allow a password to be established for the filter;
- (5) notify the user of the device when the filter blocks the device from accessing a website; and
- (6) allow a non-minor user who has a password the option to deactivate and re-activate the filter.

Enacted by Chapter 166, 2024 General Session
